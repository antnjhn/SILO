Set up games from another PC
This library was recorded on another machine, so its save folders still point at paths that do not exist here. Nothing is moved or deleted — each step only points a game at where its saves live on this PC.
1. Relink save folders
Finds each game's save folder on this machine and points it there. Games SILO cannot place are named, not guessed.
2. Bring saves across
Copies save folders in for games with nowhere here to point — from the old PC's drive, or from that game's own SILO backup.
Anything still left over can be linked by hand: open a game, choose Edit, then Find on this PC beside Save Folder.
